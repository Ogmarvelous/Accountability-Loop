# Accountability-Loop

**Accountability-Loop** is a cross-platform mobile application built with React Native and Expo designed to help chronic procrastinators stay consistent by pairing them with accountability partners for their daily tasks.

## Overview

Many productivity apps fail because they rely solely on willpower and solo checklists. Accountability-Loop turns daily task completion into a shared commitment—helping users break through procrastination by connecting with an accountability partner who tracks progress, encourages follow-through, and keeps daily goals on schedule.

## Key Features

- **Accountability Partner Pairing:** Connect with a partner to share daily goals and stay answerable to real human check-ins.
- **Daily Task & Goal Tracking:** Create, organize, and check off daily tasks with clear completion visibility.
- **Progress & Streak Accountability:** Build consistent habits by maintaining daily completion loops with partner support.
- **Cross-Platform Experience:** Built with Expo and TypeScript to run seamlessly across Android, iOS, and the web.

## Tech Stack

- **Framework:** React Native & Expo (File-based routing)
- **Language:** TypeScript / JavaScript
- **License:** MIT
